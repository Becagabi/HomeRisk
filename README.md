# HomeRisk
### Data-Driven Property Risk Intelligence

O **HomeRisk** é uma aplicação web desenvolvida para integrar dados imobiliários e indicadores de risco, permitindo analisar vulnerabilidades, identificar padrões e apoiar a priorização de ações preventivas.

A plataforma reúne informações sobre imóveis, características das regiões e indicadores de infraestrutura para oferecer uma visão analítica dos fatores que podem influenciar a avaliação de risco de uma propriedade.

### Objetivo do projeto

Transformar dados imobiliários e informações de vistorias em indicadores que facilitem a análise de riscos, a comparação entre regiões e a tomada de decisões baseada em dados.

### Principais funcionalidades

- Análise de risco de imóveis e regiões.
- Monitoramento de indicadores de vulnerabilidade.
- Comparação entre risco e mercado imobiliário.
- Visualização de indicadores, métricas e históricos.
- Organização e consulta de dados para apoiar análises preventivas.

### Tecnologias utilizadas

HTML, CSS, JavaScript, Chart.js, Python, SQLite, SQL e arquivos CSV.

**HomeRisk — Transformando dados em inteligência para análise de riscos imobiliários.**
